# 07 — Integrated Pomodoro Timer

**What to build:** An in-app Pomodoro timer widget capable of binding to any active task, providing start/pause/reset controls, visual countdown ring, session counter, and accumulating focus minutes into task metadata.

**Blocked by:**
- 03 — Basic Task CRUD & List UI

**Status:** ready-for-agent

- [ ] Build Pomodoro Timer UI component with smooth countdown display ring and controls (Start, Pause, Reset).
- [ ] Allow selecting/attaching a specific task to the current Pomodoro focus session.
- [ ] Support timer modes (25min Focus, 5min Short Break, 15min Long Break).
- [ ] Provide in-app visual and sound chime when focus session completes.
- [ ] Increment task's `completedPomodoros` and total focus minutes upon session completion.
